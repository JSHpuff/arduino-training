# 02 BareMinimum 最簡程式架構

## 簡介
展示 Arduino 程式的最簡骨架，包含 setup 與 loop 兩個核心函式，說明微控制器開機後的初始化常式與週期性主迴圈運作機制。

## 硬體接線表
本單元為純軟體架構驗證，無需外接任何電子元件。

## 架構要點
* `setup()`：微控制器重置或通電後僅執行一次，用於配置接腳方向、初始化串口或周邊模組。
* `loop()`：於 setup 執行完畢後進入無窮迴圈重複呼叫，為系統的主輪詢常式。
* 底層進入點：Arduino 於底層 main.cpp 中已先行呼叫 init 函式完成 Timer0 與全域中斷初始化，隨後才呼叫 setup 與進入 loop 迴圈。

## 模擬方式
* 複製本目錄之 sketch.ino 與 diagram.json 內容至 Wokwi 線上編輯器即可直接執行模擬。
