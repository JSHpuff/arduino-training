# 04 Fade 呼吸燈與 PWM 調光

## 簡介
透過微控制器硬體計時器輸出脈衝寬度調變 PWM 訊號，週期性調節工作週期占空比，實現發光二極體漸亮與漸暗的呼吸燈視覺效果。

## 硬體接線表

| 元件名稱 | 元件腳位 | Arduino Uno 腳位 | 備註說明 |
| :--- | :--- | :--- | :--- |
| 紅色 LED | 陽極正極 | 數位第 9 腳 | 具備硬體 PWM 輸出接腳 |
| 紅色 LED | 陰極負極 | 限流電阻端 | 串接 220 歐姆限流電阻 |
| 限流電阻 | 接地端 | GND | 系統共用參考地線 |

## 電路與韌體設計要點
1. **硬體 PWM 工作原理**：數位接腳 9 由 ATmega328P 的 Timer1 比較輸出通道 A 驅動，透過調節方波高電位持續時間佔整個週期的比率，以 0 至 255 的占空比控制發光二極體的平均發光能量。
2. **三角波漸變演算法**：設定亮度步進值，當亮度累加至 255 或遞減至 0 時反轉步進符號，產生連續往返的漸變效果。
3. **序列埠數值監控**：以 115200 波特率即時回傳當前占空比數值，便於透過序列繪圖家繪製三角波形。

## 模擬方式
* 複製本目錄之 sketch.ino 與 diagram.json 內容至 Wokwi 線上編輯器即可直接執行模擬。
* 啟動模擬後，可觀察紅色 LED 呈現連續平滑的漸亮漸暗呼吸燈效果，並於序列埠視窗觀察 0 至 255 的數值跳變。
